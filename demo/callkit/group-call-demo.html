发起多人通话功能演示

✨ 新增功能特性

  • 主动发起群组通话：无需等待邀请，可以主动发起视频或语音群组通话
  • 成员选择界面：发起通话前先选择要邀请的群成员
  • 多选支持：可以同时选择多个成员参与通话
  • 即时开始：选择完成员后立即开始通话，无需等待接听
  • 通话类型区分：支持视频通话和语音通话两种模式

🚀 使用步骤

  1. 在应用中添加 CallKit 组件，并设置 groupMembers 属性
  2. 调用 callKitRef.current?.startGroupCall('video') 或 startGroupCall('audio')
  3. 系统会自动弹出群成员选择界面
  4. 选择要邀请的成员（支持多选）
  5. 点击"确定"按钮
  6. 通话立即开始，包含所有选中的成员

📋 代码示例

// 1. 获取 CallKit 引用 const callKitRef = useRef<CallKitRef>(null); // 2. 发起视频群组通话 const handleStartVideoGroupCall = () => { callKitRef.current?.startGroupCall('video'); }; // 3. 发起语音群组通话 const handleStartAudioGroupCall = () => { callKitRef.current?.startGroupCall('audio'); }; // 4. 配置 CallKit 组件 <CallKit ref={callKitRef} groupMembers={mockGroupMembers} onCallStart={handleCallStart} // ... 其他配置 />

🎯 应用场景

  • 团队会议：项目经理快速发起团队会议，选择相关成员参与
  • 客户沟通：销售人员邀请技术专家和客户进行三方通话
  • 教育培训：老师发起小组讨论，选择特定学生参与
  • 家庭通话：组织家庭视频聊天，选择在线的家庭成员

🔧 技术实现

  1. 状态管理：新增 isInitiatingGroupCall 状态跟踪发起通话流程
  2. 用户选择：复用现有的 UserSelect 组件进行成员选择
  3. 动态标题：根据通话类型动态设置选择界面标题
  4. 视频创建：自动为选中的成员创建视频流对象
  5. 回调处理：通过 onCallStart 回调通知外部通话开始
