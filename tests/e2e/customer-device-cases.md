# 客户通话规范：设备环境执行用例

这些用例对应 `customer-scenario-spec.md` 中不能由桌面 Chromium 证明的条件。每条独立执行；A、B、C、D 和 B2 的含义与原规范相同。执行时记录设备型号、系统版本、应用版本、呼叫服务环境、网络类型、通话 ID、各端快照及时间。在线且呼叫通道就绪的观察端都查询服务端快照；故障期间查不到的端记录当时 UI 和回调，恢复后再查询。每条结束时清理所有参与者并确认可立即再拨。

| 编号 | 前置与操作 | 观察端及通过条件 |
| --- | --- | --- |
| OFF-01 | B 关闭应用呼叫连接并保持离线；A 分别发起一对一和会议邀请，B 不打开应用，只观察系统推送。 | A 快照进行中、B 待接听；B 可收到系统唤醒，但应用内没有来电、铃声或媒体。恢复连接后再查询 B 的快照，不凭推送判定通话状态。 |
| OFF-05 | 在可控离线数据环境中为 B 准备一条已过期邀请；B 登录、完成呼叫就绪并拉取该条。 | B 不出现来电或铃声；服务端快照若已结束应核对具体结束原因，不得把过期内容恢复为待接听。 |
| DEV-02 | A、B 已接通；分别拔出耳机、拔出摄像头或让设备被其他应用占用，再恢复设备并重新打开。 | 对应声音／画面中断有可见提示；两端快照始终进行中、设备不变。恢复后对应媒体回来且每种媒体只发布一次，对端不继续订阅失效轨道。 |
| NS-01 | A 在拨出中从 Wi-Fi 切到蜂窝，覆盖创建响应已到和未到两次执行。 | A、B 就绪后查快照：已创建则只有原通话且 A 拨出、B 待接听或振铃；未创建则没有进行中通话。不得显示伪造的拒绝／超时。 |
| NS-02 | B 振铃时切到另一网络；一次保持邀请有效，一次在切换期间由 A 取消。 | 有效邀请在 B 就绪后只出现／继续一次；取消的邀请停止振铃。A、B 最终快照与 UI 相同，取消原因为 `canceled`。 |
| NS-03 | 已接通的一对一和三人会议分别执行；有效设备在 Wi-Fi 与蜂窝间往返切换两次。 | 每次重新完成呼叫就绪后才恢复媒体。两端／三端仍是同一通话 ID、设备不变，创建、接通、接听时间不变，不产生第二通。 |
| NS-04 | B 点击接听但响应未返回时切网；分别准备服务端已处理和未处理的结果。 | B 就绪后查快照：已处理则进入原通话且设备为 B；未处理则仍可接听。两端不出现两个有效设备或两个参与者记录。 |
| NS-05 | B 振铃中开始切网，完成前 B2 接听。 | B2 保持原通话和媒体；B 就绪后停止振铃、空闲、不发布媒体。快照中 B 账号的有效设备是 B2。 |
| NS-06 | A、B、C 会议中准备接听、离开和追加邀请；B 切网期间让其漏掉成员通知。 | B 就绪后以全量快照覆盖旧成员列表，显示待接听、已离开、仍在会的人；A、C 最终一致。公开 SDK 无 `revision`，记录服务端／SDK 提供的可观察排序证据。 |
| NS-07 | B 已接通第一通，切网期间 C 向 B 发起第二通；覆盖创建直接占线、创建成功但待处理、第二通已结束三种结果。 | 第一通快照、设备和媒体按恢复结果处理；第二通不覆盖第一通 UI 或媒体。新请求占线失败则无来电；若新通话仍待处理，B 不接入并报忙，核对 `busy` 终态；已结束则不补来电。 |
| NS-08 | 连接可用而呼叫通道就绪失败；同时同步一次会话或联系人，然后恢复呼叫通道。 | 聊天同步成功。呼叫不可用、不来电、不恢复媒体；本地缓存不宣称已知通话结束。就绪后查快照，再恢复或退出。 |
| DEVICE-01 | 使用真实麦克风、听筒、扬声器、蓝牙耳机进行语音和视频通话，通话中逐个切换路由。 | 双方听到正确对端声音、看到远端画面；路由切换后仍是原通话，快照参与者与时间不变。记录实际音频输出设备。 |
| DEVICE-02 | 已接通后分别锁屏、切后台，再回应用；覆盖服务端仍进行且本机有效、已结束、本机失去有效设备三种结果。 | 回前台并就绪后先查快照，再恢复原媒体或退出。通话 ID 和时间不被重写；后台媒体中断本身不作为服务端结束依据。 |
| DEVICE-03 | 应用通话中接入系统电话，系统电话结束后回应用；同样覆盖原通话继续、已结束和设备失权。 | 系统电话期间音频按系统要求暂停／切换；回应用后以快照决定恢复。原通话媒体不串到另一应用内通话，不残留对端声音。 |
| DEVICE-04 | 杀死应用或保持离线后由 A 发邀请；分别在有效、取消、超时后点击系统通知冷启动。 | 有效邀请在呼叫就绪及快照核对后进入来电；失效邀请不进入来电。系统通知只作唤醒，不单独判定通话状态。 |
| DEVICE-05 | 在真机按 NS-01 ～ NS-07 顺序各执行一次，记录每次切换前后的 Wi-Fi／蜂窝类型。 | 对应 NS 用例的各端 UI、信令、媒体和服务端快照全部满足；仅断开网络或开飞行模式不能记为已执行。 |

`OFF-01`、`OFF-05` 需要真实推送或可控的离线数据。如果环境不具备，应记录“未执行”和缺少的前置条件，不以浏览器在线来电替代。`NS-*`、`DEVICE-*` 需要真实手机与网络，桌面 Playwright 不计通过。
