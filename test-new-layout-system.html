新布局系统的优势：

  • 完全分离的布局逻辑：每种布局模式都有独立的组件，包含完整的 UI 结构
  • OneToOne 真正的画中画：视频内容占满整个容器，Header 和 Controls 浮动在上面
  • 灵活的布局管理：可以轻松添加新的布局模式（如语音通话、屏幕共享等）
  • 职责分离清晰：CallKit 只负责状态管理，布局逻辑完全由 Layout 组件处理
  • 易于扩展：每个布局都是独立的，可以单独优化和测试

支持的布局模式：

  • ONE_TO_ONE：1v1 视频通话，画中画布局
  • MULTI_PARTY：多人视频通话，网格布局
  • PREVIEW：预览模式，用于通话前的设备检测
  • MINIMIZED：最小化模式，显示简化的控制界面
  • VOICE_CALL：语音通话模式（待实现）
  • SCREEN_SHARE：屏幕共享模式（待实现）
